# Blue Banana X Athletics: website concept

A concept website for a Blue Banana Athletics line, built for a consulting project at
university. It's a single page in plain HTML, CSS and JavaScript, with no framework and no
build step.

---

## What's on the page

- **Landing.** A full-screen hero with staggered fade-up animation.
- **Transition.** A section that hands off from the brand into the new line.
- **Athletics.** The concept collection: "performance built for the urban athlete".
- **Catalog.** Product sections with numbered headers, for browsing once the campaign has
  done its job.
- **Custom cursor.** Replaces the system pointer across the page, so the site feels like a
  brand object and not a template.

**Type:** Bebas Neue for display, DM Sans for body text, Space Mono for labels and numbers.

---

## Running it

Open `index.html` in a browser. That's the whole setup.
